# ptopchat

Чат между двумя локальными сетями. В каждой сети на сервере запускается хост. Рабочие станции открывают веб-страницу этого хоста и не подключаются ко второй сети напрямую. Серверы связаны одним TCP-каналом: общий секрет проверяется HMAC и шифрует кадры AES-GCM.

По каналу ходят текстовые сообщения и файлы. История хранится на диске каждого хоста (SQLite и каталог файлов). После обрыва исходящие сообщения досылаются, а недостающие за окно истории подтягиваются по id.

Интерфейс на русском и английском. Переключатель RU/EN на странице, выбор запоминается в браузере. Текст сообщений, имена и названия файлов не переводятся.

## Требования

Python 3.11 или новее.

```bash
pip install -r requirements.txt
```

## Два сайта на одной машине

В двух терминалах из корня репозитория:

```bash
python -m ptopchat config.site-a.example.toml
python -m ptopchat config.site-b.example.toml
```

Откройте две вкладки: [http://127.0.0.1:8080](http://127.0.0.1:8080) и [http://127.0.0.1:8081](http://127.0.0.1:8081). Имя берётся из конфига. В поле «Куда» выберите адрес другого сайта, отправьте текст и файл. Второе окно должно показать то же сообщение и дать скачать файл уже со своего хоста. Адрес своего сайта оставляет сообщение только в этой сети.

Перед использованием смените `shared_secret` в обоих файлах на одно и то же длинное значение. Ровно один хост должен быть с `dial = true`.

## Две разные сети

1. На сервере A оставьте `dial = false` и откройте TCP-порт `p2p_port` (в примере 9700) для сервера B.
2. На сервере B поставьте `dial = true` и `peer_addr = "<IP сервера A>:9700"`.
3. Рабочие станции ходят только на HTTP своего сервера, например `http://192.168.1.10:8080`.

Хост, который слушает, должен быть доступен со второго сервера по обычному TCP. Обход NAT в эту версию не входит. Сеть офиса считается доверенной: страница не спрашивает пароль у рабочей станции.

## Конфиг

- `site_name` — название сайта
- `name` — имя отправителя для всех сообщений с этого хоста
- `address` — адрес этого хоста (`host:port`), его можно выбрать как назначение
- сообщения на `address` остаются в этой сети; адрес соседа уходит по каналу между серверами
- `http_host`, `http_port` — страница чата
- `p2p_host`, `p2p_port` — канал между серверами
- `dial` — `true` только у одного из двух хостов
- `peer_addr` — `host:port` слушающего хоста, обязателен при `dial = true`
- `shared_secret` — общий секрет канала
- `data_dir` — история и файлы
- `max_file_bytes` — лимит размера файла, по умолчанию 100 МиБ

Окно догона истории — 500 последних сообщений. Куски файла по каналу — 64 КиБ.
